# Kumbhani Digital — Asset Placeholders

Place your production assets in these folders:

## 📁 assets/images/
- `hero-illustration.svg`  — Hero section main visual
- `about-team.jpg`         — Team photo (About page)
- `og-banner.png`          — Open Graph social share image (1200×630px)

## 📁 assets/icons/
- `favicon.png`            — Browser tab icon (32×32px)
- `apple-touch-icon.png`   — iOS home screen icon (180×180px)
- `logo.svg`               — Main logo (dark background)
- `logo-white.svg`         — White version for footer

## 📁 assets/fonts/
- (Optional) Drop custom `.woff2` font files here if self-hosting
