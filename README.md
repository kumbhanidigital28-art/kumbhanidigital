# Kumbhani Digital — Website

> **Your Partner in Digital Innovation** | Surat, India

---

## 🚀 Project Overview

Official website for **Kumbhani Digital** — a full-service IT company offering Web Development, App Development, AI Solutions, Digital Marketing, and UI/UX Design.

---

## 📁 Folder Structure

```
kumbhani-digital/
├── index.html              ← Homepage
├── about.html              ← About Us page
├── services.html           ← Services page
├── contact.html            ← Contact page
├── privacy.html            ← Privacy Policy
│
├── css/
│   ├── reset.css           ← Browser reset
│   ├── variables.css       ← Design tokens (colors, fonts, spacing)
│   ├── global.css          ← Layout, navbar, buttons, footer
│   ├── components.css      ← Reusable components (cards, CTAs, etc.)
│   ├── animations.css      ← Keyframes & scroll-reveal system
│   └── pages/
│       ├── home.css        ← Homepage-specific styles
│       ├── about.css       ← About + shared page-hero styles
│       ├── services.css    ← Services detail section styles
│       ├── contact.css     ← Contact form & info panel
│       └── privacy.css     ← Privacy page typography
│
├── js/
│   ├── utils.js            ← Shared helpers (debounce, qs, etc.)
│   ├── nav.js              ← Sticky header & mobile menu
│   ├── animations.js       ← IntersectionObserver scroll reveals
│   └── main.js             ← Entry point — bootstraps all modules
│
└── assets/
    ├── images/             ← Photos, illustrations, OG images
    ├── icons/              ← Logo, favicon, touch icons
    └── fonts/              ← Self-hosted fonts (optional)
```

---

## 🛠️ Tech Stack

- **HTML5** — Semantic, accessible markup
- **Vanilla CSS** — Custom design system with CSS variables
- **Vanilla JS (ESM)** — No dependencies, no build step needed
- **Google Fonts** — Poppins (300–800 weights)

---

## 🎨 Design System

| Token | Value |
|---|---|
| Primary Color | `#6C63FF` (Electric Violet) |
| Accent Color | `#00D4FF` (Cyber Cyan) |
| Background | `#0A0B1A` (Deep Space) |
| Font | Poppins |

---

## ✅ Features

- 🌙 Dark mode by default, light mode via `prefers-color-scheme`
- 📱 Fully responsive (mobile-first)
- ♿ Accessible — ARIA labels, semantic HTML, focus states
- ⚡ Scroll-reveal animations with `IntersectionObserver`
- 🔢 Animated number counters
- 🍔 Mobile hamburger menu
- 📬 Contact form with validation & async submit
- 🔍 SEO-ready (meta, OG tags, robots)
- 🎭 No build tools required — open `index.html` directly
